# COS30043 — Project Scope

**Unit:** COS30043 Interface Design and Development
**Weight:** 40% of total marks
**Type:** Individual project

---

## What the assignment asks for

Design and develop a full-stack web application using Vue 3 on the frontend and any backend technology, connected through a RESTful API. The application must have a clear separation between frontend and backend, consist of at least 8 interconnected pages, and demonstrate understanding across four learning outcomes.

---

## Four graded areas (ULOs)

**ULO 1 — Interface design principles**
The UI must show contextual grouping of elements, a consistent grid-based layout, clear visual hierarchy, and consistent navigation design.

**ULO 2 — Contemporary frameworks**
Vue 3 is mandatory. Must demonstrate component-based architecture, reusable components, Vue directives, dynamic data binding, and asynchronous API data retrieval.

**ULO 3 — Multi-device design**
Mobile-first responsive design across at least 3 device sizes. Screenshots at each size are required in the report, along with a written explanation of how responsiveness is implemented.

**ULO 4 — Usability and accessibility evaluation**
Evaluate the UI against usability and accessibility standards. Identify issues, evaluate navigation and form usability, and propose improvements. This goes in the report.

**Backend**
Functional RESTful API with a database handling full CRUD operations.

---

## HD requirement

To reach HD, I need to independently explore techniques beyond lecture content and document every one of them in the report. The brief lists these as examples:

- Advanced Vue features
- External API integrations
- Advanced component design patterns
- Performance optimisation techniques
- Advanced UI interactions or animations
- Improved accessibility features

Anything not written up in the report does not get marked. Documentation is not optional.

---

## Deliverables

- Full source code (frontend and backend)
- Project report covering: cover page, introduction and system overview (2-3 pages), wireframe diagrams, screenshots at 3 device sizes, responsive UI description (2-3 pages), usability and accessibility evaluation (1-3 pages), and the advanced techniques section
- Video presentation uploaded to YouTube — URL on the cover page
